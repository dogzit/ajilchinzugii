# Агуулга оруулах заавар (редакторт)

Энэ заавар нь **програмчлал мэддэггүй** хүнд зориулагдсан. Дарааллаар дагаад
хийвэл болно. Юм эвдэх гэж айх шаардлагагүй: бүх өөрчлөлт хувилбараар
хадгалагддаг, нийтлэхээс өмнө «draft» (ноорог) хэлбэрээр хэвээр байна.

> **Анхааруулга:** удирдлагын хэсгийн (admin) **цэс, товчнууд англиар** байна.
> Payload CMS-д монгол хувилбар байхгүй. Харин бидний нэмсэн **талбарын нэр,
> тайлбар бүр монгол дээр** (жишээ: «Гарчиг / Title»). Товчны англи нэрийг
> доор хаалтанд бичсэн байгаа.

---

## 1. Нэвтрэх

1. Хөтөч дээр сайтын хаягийн сүүлд `/admin` гэж бич.
   Жишээ: `https://<сайтын-хаяг>/admin`
2. И-мэйл, нэвтрэх үгээ бич → **Login**.

**Хэрэв хэн ч байхгүй, хамгийн анх удаа нэвтэрч байгаа бол:** систем өөрөө
«Create first user» хуудас гаргана. Тэндээ байгууллагын и-мэйл, хүчтэй
нэвтрэх үг (12-оос дээш тэмдэгт) оруул. Энэ эхний хүн **Админ** болно.

Нэвтрэх үгээ мартвал **Forgot password** дээр дар.

**Хоёр төрлийн эрх байна:**

| Эрх               | Юу хийж чадах                                       |
| ----------------- | --------------------------------------------------- |
| Админ (Admin)     | Бүх агуулга + хэрэглэгч нэмэх, эрх солих            |
| Редактор (Editor) | Бүх агуулга бичих, нийтлэх. Хэрэглэгч нэмж чадахгүй |
|                   |                                                     |

Шинэ хүн нэмэхийг зөвхөн админ хийнэ: зүүн цэсний **Users** → **Create new**.
Сайт дээр гаднаас хүн өөрөө бүртгүүлэх боломж **байхгүй** (зориуд).

---

## 2. Удирдлагын хэсгийн бүтэц

Зүүн талын цэс гурван хэсэгт хуваагдана:

- **Агуулга / Content** — Судалгаа (Papers), Хамт олон (Team), Хамтрагчид
  (Partners), Зураг файл (Media), Аргачлал (Methodology), Бодлого (Policy)
- **Өгөгдөл / Data** — Нөлөөллийн тоо (Impact snapshot). Зөвхөн **харах**.
- **Тохиргоо / Settings** — Сайтын тохиргоо (Site), Хэрэглэгчид (Users)

---

## 3. Хоёр хэл (монгол / англи)

Сайт монгол (үндсэн) ба англи хэлтэй. Засварлах хуудасны **баруун дээд талд
хэлний сонголт (Locale)** байна: `Монгол` / `English`.

> **Эхний удаад** тэнд `Locale: undefined` гэж гарч болзошгүй. Энэ нь алдаа
> биш — та хэлээ нэг удаа сонгоход тогтоно. Дарж `Монгол`-ыг сонго.

1. Монгол дээрээ текстээ бич → **Save**.
2. Дараа нь **Locale**-ийг `English` болго → ижил талбаруудыг англиар бич →
   **Save**.

> Англи нь хоосон бол сайт дээр **монгол текст** харагдана (fallback). Тийм
> учраас англиа дүүргэх хүртэл хуудас хоосон харагдахгүй. Гэхдээ зургийн alt
> текст **хоёр хэл дээр хоёуланг шаарддаг** — хоосон бол хадгалахгүй.

---

## 4. Сайтын үндсэн текст засах (Site)

**Тохиргоо / Settings → Сайтын тохиргоо (Site)**

| Талбар              | Юу бичих                                                 |
| ------------------- | -------------------------------------------------------- |
| Эрхэм зорилгын мөр  | Нэг өгүүлбэр. Нүүр хуудсан дээр гарна.                   |
| Холбоо барих и-мэйл | Нэг и-мэйл хаяг. Сайт дээр **текстээр** харагдана.       |
| Сошиал хаягууд      | **Add row** → платформын нэр + `https://`-ээр бүтэн хаяг |
| Байгууллага         | Хуулийн нэр, байгуулагдсан өдөр, хот                     |
| SEO                 | Хайлтын гарчиг (60 тэмдэгт), тайлбар (160 тэмдэгт)       |

Дараа нь **Save**.

**SEO тэмдэгтийн тоолуур:** талбарын доор `12/60 тэмдэгт / characters` гэж
гарна. Хэтэрвэл **улаан** болж «хэт урт / too long» гэж сануулна. Хэтэрсэн
тохиолдолд хадгалахгүй — тоог хасаад дахин оролд.

---

## 5. Судалгаа (paper) нэмэх, PDF хавсаргах

**Агуулга / Content → Судалгаа (Papers) → Create new**

1. **Гарчиг / Title** — судалгааны нэр (монголоор).
2. **Slug (URL)** — баруун талын хэсэгт. Гарчгаас автоматаар гарна.
   Жишээ: `huuhdiin-hodolmor-2026`. Зөвхөн жижиг латин үсэг, тоо, зураас.
   **Нийтэлсний дараа солихгүй** — хуучин линк эвдэрнэ.
3. **Хураангуй / Abstract** — текст засварлагчид бич.
4. **Зохиогчид / Authors** — **Add row** дээр дарж нэг нэгээр нэм.
   Нэрийг **эшлэлд байх ёстой хэлбэрээр** бич (жишээ: `Б. Болормаа`).
   Систем нэрийг өөрчлөх, товчлохгүй.
5. **Он / Year**, **Нийтлэлийн төлөв** — баруун талд.
6. **Хэвлэл / Venue**, **DOI** — байвал бич. DOI жишээ: `10.1234/abcd.2026`.
7. **PDF файл** — **Choose from existing** эсвэл **Upload new**:
   - Upload new → файлаа сонго
   - **Alt текст (монгол)** ба **(англи)** — хоёуланг бич (жишээ:
     «Судалгааны тайлангийн PDF»)
   - **Файлд хэн байна** = `Хүн байхгүй` (PDF-д хүний зураг байхгүй бол)
   - **Save**
8. **Кодын хаяг / Өгөгдлийн хаяг** — байвал `https://`-ээр бүтэн бич.
9. **Эшлэл (автоматаар)** — APA ба BibTeX **өөрөө бүрдэнэ**. Гараар
   бичих шаардлагагүй, засах ч боломжгүй. Хадгалах болгонд шинэчлэгдэнэ.
10. Монголоо хадгалсны дараа **Locale → English** болгоод гарчиг, хураангуйг
    англиар бич → **Save**.
11. Бэлэн болмогц **Publish changes** дээр дар.

> **Ноорог (draft) ба нийтлэх (publish):** **Save draft** дарвал зөвхөн та
> харна, сайт дээр гарахгүй. **Publish changes** дарсны дараа л гадны хүн
> харна. Буцаахыг хүсвэл **Versions** таб дээрээс хуучин хувилбарыг сонгож
> **Restore** дар.

---

## 6. Бодлогын төлөв шинэчлэх (Policy)

**Агуулга / Content → Бодлого (Policy)**

Төлөв өөрчлөгдөх бүрт **хоёр** зүйл хийнэ:

1. Баруун талын **Төлөв / Status** -ыг шинэ төлөв болго
   (Боловсруулсан → Хүргүүлсэн → Хэлэлцэгдэж байна → Батлагдсан / Татгалзсан),
   мөн **Төлвийн огноо / Date of this status** -ыг тэр өдрөөр тавь.
2. **Явцын бүртгэл / History** → **Add row** → огноо, төлөв, тэмдэглэл нэм.
   **Хуучин мөрийг дарж бичихгүй** — түүх бүтнээрээ харагдах ёстой.

Дараа нь **Publish changes**.

---

## 7. Аргачлалын өөрчлөлтийн бүртгэл (change log)

**Агуулга / Content → Аргачлал (Methodology)**

Тодорхойлолт (definitions) эсвэл тоолох журам (counting rules) -ыг **өчүүхэн
ч өөрчилвөл** доорх бүртгэлд нэг мөр нэмнэ:

1. **Өөрчлөлтийн бүртгэл / Change log** → **Add row**
2. **Огноо** = өнөөдөр
3. **Юу өөрчлөгдсөн** = жишээ: «"Шийдвэрлэсэн хэрэг"-ийн тодорхойлолтод
   зуучлалаар эцэслэсэн тохиолдлыг нэмж тооцохоор болов.»
4. **Publish changes**

> **Anchor id-г хэзээ ч солихгүй.** Тодорхойлолт, журам бүрт `anchorId`
> (жишээ: `counting-cases`) байна. Сайт дээрх тоонууд шууд түүн рүү
> холбогддог. Солих шаардлага гарвал програмистад хэлнэ.

---

## 8. Зураг оруулах — зөвшөөрөлтэйгөөр

**Агуулга / Content → Зураг, файл (Media) → Create new**

1. **Upload** — зургаа сонго.
   - Систем файлын нэрийг **өөрөө санамсаргүй болгоно** (жишээ
     `9f2a71c4.webp`). Хүний нэр агуулсан файлын нэр сайт дээр гарахгүй.
   - Зургийн **EXIF/GPS мэдээлэл автоматаар бүрэн хасагдана** (хаана авсан нь
     мэдэгдэхгүй).
2. **Alt текст (монгол)** + **Alt текст (англи)** — хоёуланг бич. Харж
   чадахгүй хүнд юу байгааг тайлбарла.
3. **Файлд хэн байна / Who is in this file**:
   - `Хүн байхгүй` — лого, баримт бичиг, объект
   - `Насанд хүрсэн гишүүн` — 18+ хүн
   - `Хүүхэд, залуу гишүүн` — 18 хүрээгүй хүн
4. **Хэрэв `Хүүхэд, залуу гишүүн` сонговол дөрвөн нөхцөл гарч ирнэ. Дөрвүүлээ
   биелээгүй бол систем хадгалахгүй:**
   - ☑ Хүүхдийн бичгээр зөвшөөрөл байна
   - ☑ Эцэг эх, хуулийн ээлжит хүний бичгээр зөвшөөрөл байна
   - Зөвшөөрлийн огноо
   - Бичгийн баримтын дугаар — **хүүхдийн нэрийг энд бичихгүй**, зөвхөн
     «Зөвшөөрөл A-12, 2026 оны хавтас» гэх мэт хаана байгааг заа
5. **Save**

> Хэрэв зөвшөөрөл бүрэн биш бол «Хүүхэд, залуу гишүүний зураг хадгалахын
> тулд дараах нь шаардлагатай: ...» гэсэн алдаа гарна. Энэ зөв ажиллаж
> байгаа гэсэн үг. Бичгээр зөвшөөрөл гартал зургийг оруулахгүй.

---

## 9. Хамт олон, хамтрагчид

**Хамт олон (Team)** — зөвхөн **насанд хүрсэн** хүн. Мөр нэмэхдээ баруун
талын ☑ **«Энэ хүн 18 нас хүрсэн гэдгийг баталж байна»** -ыг тавих ёстой,
үгүй бол хадгалахгүй. 18 хүрээгүй хүнийг **нэрээр ч, зургаар ч** энд
оруулахыг хориглоно.

**Хамтрагчид (Partners)** — нэр, лого, `https://`-тэй хаяг. Зөвшөөрөлгүй
байгууллагын лого тавихгүй.

---

## 10. Хийж болохгүй зүйлс

1. **Тоо гараар бичихгүй.** Нөлөөллийн тоо зөвхөн Google Sheet-ээс
   автоматаар орж ирнэ. Админ дотор **Нөлөөллийн тоо (Impact snapshot)**
   нь зөвхөн харах зориулалттай — засах талбар байхгүй.
2. **5-аас цөөн хэрэг дээр тулгуурласан тоог хэзээ ч тоогоор харуулахгүй.**
   Систем өөрөө «5-аас цөөн / Fewer than 5» гэж харуулна.
3. **Хүүхдийн нэр, сургууль, ажлын газар, зураг** — агуулгад, alt текстэд,
   файлын нэрэнд, хаягт хаана ч бичихгүй.
4. **Хувийн мэдээлэл цуглуулах форм нэмэхгүй.** Холбоо барих нь зөвхөн
   и-мэйл хаяг.
5. **Байхгүй зүйлийг зохиохгүй.** Тоо, нэр, хамтрагч, эшлэл олдоогүй бол
   `[ХҮЛЭЭГДЭЖ БУЙ / TBD]` гэж тэмдэглээд орхи.

---

## 11. Асуудал гарвал

- **Save дарахад алдаа гарна** → алдааны текстийг уншаад (монголоор бичсэн
  байгаа) дутуу талбарыг нөхнө.
- **Нийтэлсэн ч сайт дээр гарахгүй** → **Publish changes** дарсан эсэхээ,
  мөн зөв хэл (Locale) дээр бичсэн эсэхээ шалга. 1-2 минут хүлээ.
- **Хуучин хувилбар руу буцах** → **Versions** таб → хувилбар сонго →
  **Restore**.
- **Хуудас хоосон цагаан/хар харагдах, эсвэл гэнэт Login руу шидэх** →
  хөтчөө дахин ачаал (Cmd+R). Хөгжүүлэлтийн горимд сервер дахин
  хөрвүүлэх үед түр ийм болдог.
- Бусад тохиолдолд програмистад: ямар хуудсан дээр, ямар товч дарсан, ямар
  алдаа гарсныг (гаргасан зургаар) хамт хэлнэ.
