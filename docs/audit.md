## 2. CLAUDE.md-ийн 8-р дүрэм биелээгүй / Rule 8 is not met

> «≤ 100 KB client JS per route (gzipped)»

**Бодит байдал: 177 KB.** Үүнээс:

| Юу                                       | Хэмжээ | Багасгах боломж |
| ---------------------------------------- | ------ | --------------- |
| React + React DOM                        | ~70 KB | Үгүй            |
| Next App Router runtime                  | ~43 KB | Үгүй            |
| Next-ийн бусад (hydration, router state) | ~64 KB | Үгүй            |
| Манай код                                | ~0 KB  | —               |

Хуудсууд бүгд Server Component; browser руу явж буй манай код нь зөвхөн хоёр
жижиг client component (хэл сэлгэх, хуулах товч), тэдгээр нь **орчуулгын
түлхүүр биш, бэлэн мөрийг props-оор** хүлээж авдаг.

**Энэ фазад 14 KB хассан:** next-intl-ийн client runtime-ыг browser-оос бүрэн
гаргасан (191 → 177 KB, HTML 47 → 36 KB). `tests/unit/bundle-budget.test.ts`
нь дахин нэмэгдэхээс хамгаална.

**Үлдсэн 77 KB-ыг хасах цорын ганц зам нь framework солих** (жишээ нь Astro,
эсвэл React-гүй хувилбар). Энэ нь техникийн биш, **бүтээгдэхүүний шийдвэр** —
захиалагчид танилцуулж, шийдүүлэх ёстой. Хувилбарууд:

1. **Одоогийнхоор үлдэх.** Performance 0.94, бодит 4G дээр LCP ~3 сек.
   Хүртээмж, SEO, засварлах хялбар байдал бүгд биелсэн.
2. **Дэлгэцийн фонтыг (Unbounded) хасах** → ~59 KB хэмнэнэ, LCP ~2.6 сек
   болно. Брэндийн төрх өөрчлөгдөнө.
3. **Framework солих** → 100 KB-д багтана, гэхдээ Payload admin-тай холбогдох
   хэсгийг дахин бичих шаардлагатай.

## 3. Хүртээмж / Accessibility — 0 зөрчил

`@axe-core/playwright`, шошго `wcag2a, wcag2aa, wcag21a, wcag21aa`:

|     | Хуудас | Хэл     | Өнгөний горим    | Үр дүн          |
| --- | ------ | ------- | ---------------- | --------------- |
| axe | 6      | mn + en | гэрэл + харанхуй | **24/24 цэвэр** |

Нэмэлт, скан олдоггүй зүйлсийг тестээр барьсан:

- Skip link нь хамгийн эхний focus, Enter дарахад focus `<main>` руу шилждэг
- Tab-аар явахад **бүх** элемент дээр харагдах focus ring байна
- Зөвхөн гараар бүх цэсний холбоос, хэл сэлгэгч хүрнэ
- Хуулах товч гараар ажиллаж, үр дүнг `role="status"`-оор зарлана
- Хэл сэлгэгч хоёр чиглэлд, 6 хуудсанд замаа хадгална

### Энэ фазад зассан зөрчил

**`label-content-name-mismatch` (WCAG 2.5.3, serious)** — хэл сэлгэх товчны
харагдах текст («English») accessible name-д агуулагдахгүй байв: `aria-label`
нь түүнийг монгол өгүүлбэрээр бүрэн орлуулж байсан. Дуу хоолойгоор удирддаг
хэрэглэгч «English» гэж хэлэхэд товч олдохгүй гэсэн үг. Одоо тайлбар нь
холбоос дотор `sr-only` мөр болж орсон, харагдах текст accessible name-ийн
хэсэг болсон. 24 хуудасны скан бүгд энэ нэг алдаанаас унаж байсан.

## 4. Аудитаар олдсон бусад алдаа / Other findings

### 4.1 Redirect-ийн хязгааргүй давталт (ноцтой)

Phase 6-ийн refactor-ын дараа нүүр хуудасны картууд **хэлний угтваргүй**
(`/methodology`) хаяг руу зааж байв. Next нь тэдгээрийг prefetch хийхэд
middleware `/mn/methodology` руу буцаана, Next дахин `_rsc` параметртэй гуйна,
дахин redirect... Нэг хуудас ачаалахад хөтөч **6,646 redirect** хийж, сүлжээ
хэзээ ч амардаггүй байв.

Зассан: бүх холбоос `localeHref(locale, path)`-аар дамжина. 6,646 → **1**.
Энэ нь Lighthouse-ийн «errors in console» болон best-practices оноог 0.96-аас
**1.00** болгосон.

### 4.2 Анхны зочлолтын 0.6 сек redirect (зөвшөөрсөн)

Үлдсэн нэг redirect нь `/mn` → `/mn`: next-intl `NEXT_LOCALE` cookie тавихын
тулд. Зөвхөн **хамгийн анхны** зочлолт дээр; дараа нь шууд 200 (тестээр
баталсан). Lighthouse үргэлж хүйтэн зочлолт хэмждэг тул оноон дээр үргэлж
харагдана. Үүнийг арилгах нь «Accept-Language-ийг зөвхөн анхны удаа хүндэтгэх»
гэсэн 1-р фазын шаардлагыг эвдэх тул **хэвээр үлдээв**.

### 4.3 Байхгүй лого (өмнөх фазад зассан)

JSON-LD нь `<site>/icon.svg` гэж зарлаж байсан ч `public/` фолдер байгаагүй.
Google Rich Results Test үүнийг **алдаа** гэж үзнэ. `public/logo.png` үүсгэж,
файл байгаа эсэхийг тестээр барьсан.

### 4.4 `NEXT_PUBLIC_SITE_URL` тохируулаагүй үед чимээгүй алдаа

Тохируулаагүй бол canonical, hreflang, sitemap, JSON-LD бүгд `localhost`
хаягийг нийтлэх байв — хайлтын систем тэр хэвээр индекслэнэ. Одоо production
build **алдаа заан зогсоно** (CLAUDE.md 9-р дүрэм).
