# Хүлээлгэн өгөх баримт — Ажилчин Зөгий

Энэ баримт нь **байгууллагад** зориулагдсан. Сайтыг хэн ямар дансаар эзэмшиж
байгаа, юуг хэрхэн өөрчлөх, ямар дүрэм автоматаар ажиллаж байгаа, домэйн
солих болон асуудал гарвал юу хийхийг бичив.

Агуулга оруулах өдөр тутмын заавар тусдаа: **[README-editor.md](README-editor.md)**.

---

## 1. Бүх данс байгууллагынх

Програмист хэн нэгний хувийн данс ашиглаагүй. Доорх данс бүр **таных**, та
нууц үгээ хэзээ ч солиж, хандалтыг хаах боломжтой.

| Үйлчилгээ                 | Юунд хэрэглэдэг                                       | Хаана нэвтрэх                    |
| ------------------------- | ----------------------------------------------------- | -------------------------------- |
| **GitHub**                | Кодын сан, автомат шалгалт, шөнийн нөөцлөлт           | github.com/dogzit/ajilchinzugii  |
| **Vercel**                | Сайтыг байршуулах (hosting), домэйн, HTTPS            | vercel.com                       |
| **Neon**                  | Postgres өгөгдлийн сан (бүх текст, судалгаа, бодлого) | console.neon.tech                |
| **Cloudflare R2**         | Зураг, PDF файлын сан + нөөцийн тусдаа bucket         | dash.cloudflare.com → R2         |
| **Google Cloud**          | Хүснэгт уншдаг service account                        | console.cloud.google.com         |
| **Google Search Console** | Хайлтад хэрхэн харагдахыг хянах                       | search.google.com/search-console |
| **Plausible**             | Зочдын тоолуур (cookie-гүй)                           | plausible.io                     |

> **Нууц үг, түлхүүрүүд** кодын санд хэзээ ч ороогүй. Тэдгээр нь зөвхөн Vercel
> болон GitHub-ийн «Secrets» хэсэгт хадгалагдана. Хэрэв түлхүүр алдагдсан гэж
> сэжиглэвэл тухайн үйлчилгээн дээрээ шинээр үүсгээд Vercel дээрх утгыг солино.

## 1.5 ⚠ Одоо сайт дээр ЖИШЭЭ өгөгдөл байна

Танд үзүүлэх зорилгоор түр агуулга суулгасан. **Утга бүр `ЖИШЭЭ:` (англиар
`SAMPLE:`) гэж эхэлнэ** — жинхэнэ тоо, нэртэй хольж болохгүй.

Жинхэнэ агуулга бэлэн болмогц нэг командаар бүгдийг нь устгана:

```bash
pnpm seed:demo:clear
```

Энэ нь жишээ судалгаа, хамт олон, хамтрагч, лого, нөлөөллийн тоог устгана.
Site/Аргачлал/Бодлогын текстийг **устгахгүй** — тэднийг админ дотроос өөрөө
дарж бичнэ.

> Нөлөөллийн жишээ тоо нь Google Sheet холбогдмогц **автоматаар дарагдана** —
> жинхэнэ татац амжилттай болсон даруйд хуучин snapshot солигдоно.

## 2. Тоон мэдээлэл хэрхэн шинэчлэгдэх вэ

```
Хэргийн бүртгэл (хувийн хүснэгт)
        │  IMPORTRANGE / томьёо
        ▼
Нийтийн нийлбэр хүснэгт  ──Viewer эрх──▶  Сайт  ──▶  Нөлөөлөл хуудас
```

1. Та **нийтийн нийлбэр хүснэгтээ** засна (`Totals`, `Monthly` таб).
2. Сайт **өдөрт нэг удаа, Улаанбаатарын 06:00 цагт** автоматаар уншина.
3. Шууд шинэчлэхийг хүсвэл програмистаар `/api/revalidate` дуудуулна.

Хүснэгтийн бүтэц, багана бүрийн утга: **[impact-sheet.md](impact-sheet.md)**.

> ⚠ **Хэргийн бүртгэлээ сайттай хэзээ ч бүү хуваалц.** Зөвхөн нийлбэр хүснэгт
> хуваалцагдана. Google Sheets-д «зөвхөн нэг таб» гэж эрх өгөх боломж
> **байдаггүй** — хуваалцсан файлын бүх табыг уншиж болно гэж үз.

## 3. «5-аас цөөн» дүрэм юу хийдэг вэ

Хэрэв тоо **5-аас цөөн хэрэг** дээр тулгуурласан бол сайт түүнийг **тоогоор
харуулахгүй**, оронд нь «5-аас цөөн / Fewer than 5» гэж бичнэ. Хэргийн тоог нь
ч нуудаг.

Яагаад:

- Жижиг тоо нь хүнийг таниулж болзошгүй.
- Сайт сарын тоонуудыг нийлүүлж жилийн дүн гаргадаггүй — хүснэгтийн өөрийнх нь
  дүнг авдаг. Үгүй бол уншигч харагдаж буй саруудыг дүнгээс хасаад нуусан
  тоог олчих байсан.
- График дээр нуусан сар нь **тэг биш, хоосон зай** болж харагдана.

Энэ дүрэм код дотор бичигдсэн, гараар тойрч гарах боломжгүй.

## 4. Судалгаа нэмэх

`/admin` → **Судалгаанууд** → **Create new**. Дэлгэрэнгүй алхмууд
[README-editor.md](README-editor.md) дотор, 5-р хэсэгт.

Товчхондоо: гарчиг → slug (нийтэлсний дараа **солихгүй**) → хураангуй →
зохиогчид (эшлэлд байх хэлбэрээр) → он, төлөв → PDF → **Publish changes**.

APA болон BibTeX эшлэл **автоматаар** үүснэ.

## 5. Домэйн солих

Сайт домэйноо хаана ч бичиж хадгалаагүй — зөвхөн нэг орчны хувьсагчаас уншина.
Тиймээс шилжилт нь:

1. **Vercel** → Project → Settings → Domains → шинэ домэйнээ нэм, DNS-ийг
   зааварчилсны дагуу тохируул.
2. **Vercel** → Environment Variables:
   - `NEXT_PUBLIC_SITE_URL` = `https://шинэ-домэйн`
   - `SITE_CANONICAL_HOST` = `шинэ-домэйн` (www-гүй хувилбараа сонгоно)
   - `OLD_HOSTS` = `хуучин-домэйн,www.хуучин-домэйн`
3. **Redeploy** дар.
4. Хуучин домэйныг Vercel дээр үлдээ — ингэснээр бүх хуучин холбоос шинэ
   домэйн руу **301-ээр** шилжинэ (хайлтын систем байрлалаа алдахгүй).
5. **Search Console** дээр шинэ домэйныг нэмж, sitemap-аа дахин илгээ.

Кодод өөрчлөлт хийх шаардлагагүй.

## 6. Search Console шалгах

1. search.google.com/search-console → домэйнээ сонго.
2. **Sitemaps** → `https://<домэйн>/sitemap.xml` илгээгдсэн, «Success» байх ёстой.
3. **Pages** → хэдэн хуудас индексэд орсныг харна.
4. **Experience → Core Web Vitals** → бодит хэрэглэгчийн хурдыг харуулна.

Сайт хоёр хэлтэй тул Google нь `/mn/...` ба `/en/...` хоёрыг **нэг хуудасны
хоёр хувилбар** гэж ойлгохоор тэмдэглэгдсэн.

## 7. Нөөцлөлт

- **Шөнө бүр 03:00 (Улаанбаатар)** — өгөгдлийн сангийн бүрэн хуулбар.
- **Ням гараг бүр** — зураг, файлын хуулбар.
- Хадгалах хугацаа: 30 өдрийн өдөр тутмын, 12 сарын сар тутмын.
- Нөөц нь **тусдаа bucket**-д — үндсэнийг нь устгасан ч нөөц үлдэнэ.
- Амжилтгүй болбол GitHub танд и-мэйл илгээнэ.

Сэргээх алхмууд: **[RESTORE.md](RESTORE.md)** (бодитоор туршсан).

Сард нэг удаа дараахыг шалгахыг зөвлөе: GitHub → Actions → «Nightly backup»
дээр сүүлийн ажиллалт ногоон байна уу.

## 9. Аюулгүй байдлын зарчмууд (код дотор хатуу бичигдсэн)

1. **Хүүхдийн зураг зөвшөөрөлгүйгээр хадгалагдахгүй** — хүүхэд болон эцэг эхийн
   бичгээр зөвшөөрөл, огноо, баримтын дугаар дутвал систем татгалзана.
2. **Зургийн EXIF/GPS бүрэн арилна**, файлын нэр санамсаргүй болно (анхны нэр
   нь хүний нэр агуулж магадгүй).
3. **PDF-ийн нуугдмал мэдээлэл** (зохиогч, түлхүүр үг) мөн арилна.
4. **18 хүрээгүй хүнийг** хамт олны жагсаалтад оруулах боломжгүй.
5. **Форм байхгүй** — сайт ямар ч мэдээлэл цуглуулдаггүй.
6. **Cookie**: зөвхөн нэг — таны сонгосон хэлийг санах. Тоолуур cookie
   тавьдаггүй тул зөвшөөрлийн самбар хэрэггүй.

## 10. Асуудал гарвал

| Юу болов                | Юу хийх                                                                                                                 |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Сайт нээгдэхгүй         | Vercel → Deployments → сүүлийн deploy улаан эсэхийг хар                                                                 |
| Тоо шинэчлэгдэхгүй      | Нөлөөлөл хуудсан дээр «Эх хүснэгтээс татах боломжгүй» анхааруулга байна уу? Хүснэгтийн багана солигдоогүй эсэхийг шалга |
| Зураг харагдахгүй       | Cloudflare R2 дээр bucket байгаа эсэх, `R2_PUBLIC_URL` зөв эсэх                                                         |
| Админд нэвтэрч чадахгүй | `/admin` → Forgot password                                                                                              |
| Нөөцлөлт амжилтгүй      | GitHub → Actions → Nightly backup → алдааг унш, [RESTORE.md](RESTORE.md)                                                |

дэлгэцийн зурагтай нь хамт илгээнэ үү.
