Редакторын гарын авлага

Програмчлал мэддэггүй хүнд зориулав. Дарааллаар дагаад хийвэл болно. Юм эвдэх гэж айх шаардлагагүй: бүх өөрчлөлт хувилбараар хадгалагддаг, нийтлэхээс өмнө ноорог хэвээр байна.

Эхлэхийн өмнө

Удирдлагын хэсгийн цэс, товчнууд англиар байна — Payload CMS-д монгол хувилбар байхгүй. Харин талбарын нэр, тайлбар бүр монгол дээр байгаа (жишээ: «Гарчиг / Title»). Товчны англи нэрийг доор хаалтанд бичсэн.

01

Нэвтрэх

  1. Хөтөч дээр сайтын хаягийн сүүлд /admin гэж бич. Жишээ: https://<сайтын-хаяг>/admin
  2. И-мэйл, нэвтрэх үгээ бичээд Login.

Хамгийн анх удаа бол: систем өөрөө «Create first user» хуудас гаргана. Байгууллагын и-мэйл, хүчтэй нэвтрэх үг (12-оос дээш тэмдэгт) оруул. Энэ эхний хүн Админ болно. Мартвал Forgot password.

Хоёр төрлийн эрх

ЭрхЮу хийж чадах
Админ (Admin)Бүх агуулга, нэмээд хэрэглэгч нэмэх, эрх солих
Редактор (Editor)Бүх агуулга бичих, нийтлэх. Хэрэглэгч нэмж чадахгүй

Шинэ хүн нэмэхийг зөвхөн админ хийнэ: Users → Create new. Сайт дээр гаднаас хүн өөрөө бүртгүүлэх боломжгүй — зориуд хаасан.

02

Удирдлагын хэсгийн бүтэц

Зүүн талын цэс гурван хэсэгт хуваагдана:

  • Агуулга / Content — Судалгаа (Papers), Хамт олон (Team), Хамтрагчид (Partners), Зураг, файл (Media), Аргачлал (Methodology), Бодлого (Policy)
  • Өгөгдөл / Data — Нөлөөллийн тоо (Impact snapshot). Зөвхөн харах.
  • Тохиргоо / Settings — Сайтын тохиргоо (Site), Хэрэглэгчид (Users)
03

Хоёр хэл дээр бичих

Сайт монгол (үндсэн) ба англи хэлтэй. Засварлах хуудасны баруун дээд талд хэлний сонголт (Locale) байна: Монгол / English.

  1. Монгол дээрээ текстээ бич → Save.
  2. Locale-ийг English болго → ижил талбаруудыг англиар бич → Save.

Англи нь хоосон бол сайт дээр монгол текст харагдана. Тийм учраас англиа дүүргэх хүртэл хуудас хоосон харагдахгүй. Гэхдээ зургийн alt текст хоёр хэл дээр хоёуланг шаарддаг — хоосон бол хадгалахгүй.

Эхний удаад баруун дээр Locale: undefined гэж гарч болзошгүй. Энэ нь алдаа биш — дарж Монгол-ыг сонгоход тогтоно.

Тэмдэгтийн тоолуур

SEO талбаруудын доор 21/60 тэмдэгт / characters гэж гарна. Хэтэрвэл улаан болж «хэт урт / too long» гэж сануулна — хэтэрсэн тохиолдолд хадгалахгүй.

05

Судалгаа нэмэх, PDF хавсаргах

Агуулга / Content → Судалгаанууд / Papers → Create new

  1. Гарчиг / Title — судалгааны нэр (монголоор).
  2. Slug (URL) — баруун талд, гарчгаас автоматаар гарна. Зөвхөн жижиг латин үсэг, тоо, зураас. Нийтэлсний дараа солихгүй — хуучин линк эвдэрнэ.
  3. Хураангуй / Abstract — текст засварлагчид бич.
  4. Зохиогчид / Authors — Add row дээр дарж нэг нэгээр нэм. Нэрийг эшлэлд байх ёстой хэлбэрээр бич (жишээ: Б. Болормаа). Систем нэрийг өөрчлөх, товчлохгүй.
  5. Он / Year, Нийтлэлийн төлөв — баруун талд.
  6. Хэвлэл / Venue, DOI — байвал бич. DOI жишээ: 10.1234/abcd.2026.
  7. PDF файл — Upload new → файлаа сонго → alt текстийг хоёр хэл дээр бич → Файлд хэн байна = «Хүн байхгүй» → Save.
  8. Кодын хаяг / Өгөгдлийн хаяг — байвал https://-ээр бүтэн бич.
  9. Эшлэл (автоматаар) — APA ба BibTeX өөрөө бүрдэнэ. Гараар бичих шаардлагагүй, засах ч боломжгүй.
  10. Locale → English болгоод гарчиг, хураангуйг англиар бич → Save.
  11. Бэлэн болмогц Publish changes.
Ноорог ба нийтлэх

Save draft дарвал зөвхөн та харна, сайт дээр гарахгүй. Publish changes дарсны дараа л гадны хүн харна. Буцаахыг хүсвэл Versions таб → хуучин хувилбар → Restore.

06

Бодлогын төлөв шинэчлэх

Агуулга / Content → Бодлого / Policy

Төлөв өөрчлөгдөх бүрт хоёр зүйл хийнэ:

  1. Баруун талын Төлөв / Status-ыг шинэ төлөв болго (Боловсруулсан → Хүргүүлсэн → Хэлэлцэгдэж байна → Батлагдсан / Татгалзсан), мөн Төлвийн огноо-г тэр өдрөөр тавь.
  2. Явцын бүртгэл / History → Add row → огноо, төлөв, тэмдэглэл нэм. Хуучин мөрийг дарж бичихгүй — түүх бүтнээрээ харагдах ёстой.

Дараа нь Publish changes.

07

Аргачлалын өөрчлөлтийн бүртгэл

Агуулга / Content → Аргачлал / Methodology

Тодорхойлолт эсвэл тоолох журмыг өчүүхэн ч өөрчилвөл доорх бүртгэлд нэг мөр нэмнэ:

  1. Өөрчлөлтийн бүртгэл / Change log → Add row
  2. Огноо = өнөөдөр
  3. Юу өөрчлөгдсөн — жишээ: «"Шийдвэрлэсэн хэрэг"-ийн тодорхойлолтод зуучлалаар эцэслэсэн тохиолдлыг нэмж тооцохоор болов.»
  4. Publish changes
Хэзээ ч солихгүй

Тодорхойлолт, журам бүрт anchorId (жишээ: counting-cases) байна. Сайт дээрх тоонууд шууд түүн рүү холбогддог. Солих шаардлага гарвал програмистад хэлнэ.

08

Зураг оруулах — зөвшөөрөлтэйгөөр

Агуулга / Content → Зураг, файл / Media → Create new

  1. Upload — зургаа сонго. Систем файлын нэрийг өөрөө санамсаргүй болгоно (жишээ 9f2a71c4.webp), мөн зургийн EXIF/GPS мэдээллийг бүрэн хасна — хаана авсан нь мэдэгдэхгүй.
  2. Alt текст (монгол) + (англи) — хоёуланг бич. Харж чадахгүй хүнд юу байгааг тайлбарла.
  3. Файлд хэн байна: «Хүн байхгүй» (лого, баримт), «Насанд хүрсэн гишүүн» (18+), эсвэл «Хүүхэд, залуу гишүүн» (18 хүрээгүй).
Хүүхэд, залуу гишүүн сонговол — дөрвүүлээ заавал

Дараах дөрвөн нөхцөл бүрэн биелээгүй бол систем хадгалахгүй:

  • Хүүхдийн бичгээр зөвшөөрөл байна
  • Эцэг эх, хуулийн ээлжит хүний бичгээр зөвшөөрөл байна
  • Зөвшөөрлийн огноо
  • Бичгийн баримтын дугаар — хүүхдийн нэрийг энд бичихгүй, зөвхөн «Зөвшөөрөл A-12, 2026 оны хавтас» гэх мэт хаана байгааг заа

Дутуу бол «Хүүхэд, залуу гишүүний зураг хадгалахын тулд дараах нь шаардлагатай: …» гэсэн алдаа гарна. Энэ нь зөв ажиллаж байгаа гэсэн үг.

09

Хамт олон, хамтрагчид

Хамт олон (Team) — зөвхөн насанд хүрсэн хүн. Баруун талын ☑ «Энэ хүн 18 нас хүрсэн гэдгийг баталж байна»-г тавих ёстой, үгүй бол хадгалахгүй. 18 хүрээгүй хүнийг нэрээр ч, зургаар ч оруулахыг хориглоно.

Хамтрагчид (Partners) — нэр, лого, https://-тэй хаяг. Зөвшөөрөлгүй байгууллагын лого тавихгүй.

10

Хийж болохгүй зүйлс

  1. Тоо гараар бичихгүй. Нөлөөллийн тоо зөвхөн Google Sheet-ээс автоматаар орж ирнэ. «Нөлөөллийн тоо» хэсэг зөвхөн харах зориулалттай.
  2. 5-аас цөөн хэрэг дээр тулгуурласан тоог тоогоор харуулахгүй. Систем өөрөө «5-аас цөөн / Fewer than 5» гэж харуулна.
  3. Хүүхдийн нэр, сургууль, ажлын газар, зураг — агуулгад, alt текстэд, файлын нэрэнд, хаягт хаана ч бичихгүй.
  4. Хувийн мэдээлэл цуглуулах форм нэмэхгүй. Холбоо барих нь зөвхөн и-мэйл хаяг.
  5. Байхгүй зүйлийг зохиохгүй. Тоо, нэр, хамтрагч, эшлэл олдоогүй бол [ХҮЛЭЭГДЭЖ БУЙ / TBD] гэж тэмдэглээд орхи.
